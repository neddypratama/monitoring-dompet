# 📱 Panduan Instalasi & Penggunaan Aplikasi Android DompetKu

Aplikasi **DompetKu** dirancang khusus untuk kenyamanan penggunaan di perangkat smartphone Android. Anda dapat menggunakannya dalam dua metode:

---

## 🚀 Metode 1: Instalasi File APK Langsung (Direkomendasikan untuk APK Mandiri)

File installer Android (`DompetKu.apk`) sudah disediakan di dalam sistem.

### Langkah-langkah Instalasi APK:
1. **Unduh File APK**:
   - Dari browser di HP Anda, buka halaman Login atau Pengaturan di [https://dompet.bimapratama.com/](https://dompet.bimapratama.com/).
   - Ketuk tombol **"Download DompetKu APK (Android)"** atau unduh file langsung di `https://dompet.bimapratama.com/DompetKu.apk`.
2. **Buka File Installer**:
   - Setelah selesai diunduh, buka notifikasi unduhan atau buka folder **Download** melalui aplikasi File Manager HP Anda.
   - Ketuk file `DompetKu.apk`.
3. **Izinkan Instalasi dari Sumber Tak Dikenal**:
   - Jika HP menampilkan pesan: *"Demi keamanan, ponsel Anda tidak diizinkan memasang aplikasi yang tidak dikenal dari sumber ini"*:
     - Ketuk **Setelan (Settings)**.
     - Aktifkan toggle **"Izinkan dari sumber ini" (Allow from this source)**.
     - Kembali ke layar sebelumnya dan ketuk **Instal**.
4. **Buka Aplikasi**:
   - Setelah selesai, ketuk **Buka**.
   - Icon **DompetKu** dengan logo dompet resmi akan tersedia di layar utama smartphone Anda.

---

## ⚡ Metode 2: Instalasi PWA (Progressive Web App - Tanpa Download File APK)

Metode ini adalah cara paling instan dan ringan karena langsung memanfaatkan fitur web modern Chrome di Android tanpa perlu mengaktifkan izin sumber tak dikenal:

1. Buka aplikasi **Google Chrome** di HP Android Anda.
2. Kunjungi situs resmi: **[https://dompet.bimapratama.com/](https://dompet.bimapratama.com/)**
3. Ketuk menu **titik tiga (⋮)** di sudut kanan atas browser.
4. Pilih opsi **"Tambahkan ke Layar Utama" (Add to Home screen)** atau **"Instal Aplikasi" (Install App)**.
5. Konfirmasi dengan mengetuk tombol **Instal**.
6. Aplikasi DompetKu akan langsung terpasang di HP Anda dan dapat dibuka full-screen layaknya aplikasi native Android!

---

## 🌟 Keunggulan Menggunakan Aplikasi di Android

- **Tampilan Penuh (Fullscreen)**: Tanpa bilah pencarian atau navigasi browser yang mengganggu.
- **Akses Cepat Kamera**: Mendukung pemotretan struk belanja langsung dari kamera HP untuk dianalisis oleh AI.
- **Navigasi Cepat**: Dilengkapi menu navigasi bawah (*Bottom Navigation Bar*) yang ergonomis untuk pengoperasian satu tangan.
- **Pembaruan Otomatis**: Setiap pembaruan yang diunggah ke server akan langsung aktif di aplikasi tanpa perlu install ulang.
